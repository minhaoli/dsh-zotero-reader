# Zotero 伴读

把 Zotero 里的论文直接带进 DSH 会话。助手在回答里提到库里有的文献时，右侧栏会给出入口；点开就是本地 PDF，引用、翻译和批注都在同一块界面里完成，不用再切回 Zotero 找原文。

## 能做什么

- **会话内直达原文**：正文里出现 `zotero://…` 链接时，点一下就在右侧栏打开对应论文，并跳到引用页。
- **带页码的问答**：可以按页提问、在文档内查找；回答里的页码是链接，点回原文对应位置。
- **划词翻译与解释**：选中正文即可翻译或解释，译文保留公式排版；支持原文、中英对照、纯中文三种模式与导出。
- **批注互通**：右侧栏里加的高亮、批注会写回 Zotero；本地接口不可用时自动改走云端 Web API。
- **扫描件解析**：没有文本层的 PDF 可以交给 MinerU（本地或云端）解析，之后同样能检索、翻译和批注。

## 界面

- **右侧栏**：新增「Zotero 伴读」标签，里面是论文列表和 PDF 阅读器；页码、缩放、对照模式、翻译与批注按钮都在阅读器工具条上。
- **左侧栏菜单**：新增「Zotero 伴读」一行，点开是整页设置。
- **会话正文**：`zotero://` 链接带论文标题提示，点击直接打开阅读器。

## 说明

- PDF 从本机 Zotero 数据目录读取，不会上传；翻译与问答使用当前会话选定的模型。
- 关闭插件后，右栏标签和左侧菜单入口一起消失，已保存的设置保留。
